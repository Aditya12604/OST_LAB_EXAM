# OST_LAB_EXAM
A temporary repository meant for OST Lab Exam
Here we are going to demonstrate a simple function to find whether given string is a palindrome or not
The primary code will be in the adjoining file "palindrome.cpp"
Simply download the file or paste the code into your preferred IDE 
Then simply run or use gcc compiler manually in command line
First enter the number of testcases
Then for each testcase:
Enter a string with valid ASCII characters
The Code will output:-
1. A "YES" indicating given string is already a palindrome
2. A "NO" indicting given string is not a palindrome
